## `>_` CONTRIBUTION_SNAKE.exe
### The classic — a snake that eats its way through your real contribution graph

<div align="center">
<img src="https://raw.githubusercontent.com/pritulkumarroy/pritulkumarroy/output/snake-neon.svg" width="100%"/>
</div>

**This one needs a one-time setup** (GitHub can't run scripts for you automatically — it needs your own Action to build it from your private contribution data):

1. This repo must be your **profile repo**: a public repo named exactly `pritulkumarroy` (same as your username).
2. Keep `.github/workflows/snake.yml` (already included) in that repo.
3. Go to **Settings → Actions → General → Workflow permissions** → select **"Read and write permissions"** → Save.
4. Go to the **Actions** tab → run **"Generate Snake Animation"** once manually (▶ *Run workflow*). It will also re-run automatically every day.
5. It commits the generated SVGs to a new `output` branch. The README already points at `output/snake-neon.svg` — swap the username in the URL for yours.
